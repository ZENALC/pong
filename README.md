# Pong

First Pygame project — built incrementally to learn game development fundamentals.

## Run

```
uv run main.py
```

## Stages

- [x] Stage 1 — Empty window + game loop + quit handler
- [x] **Stage 2** — Draw left paddle
- [ ] Stage 3 — Move paddle with W/S keys
- [ ] Stage 4 — Right paddle (simple AI)
- [ ] Stage 5 — Ball with velocity
- [ ] Stage 6 — Ball bounces off top/bottom walls
- [ ] Stage 7 — Ball bounces off paddles
- [ ] Stage 8 — Score + game over
